# 文化传承 H5宣传页面 PRD

## 1. 产品概述

一个关于"文化传承"主题的单页面H5宣传网站，以中国风为设计风格，主色调为中国红搭配米色/淡黄色。页面包含文化传承主题介绍、非遗科普（剪纸艺术）、校园文化（哈尔滨广厦学院）三大板块，底部设有"文化金句分享"按钮，点击弹出文化传承名言。适配手机端浏览，风格简洁美观。

## 2. 功能模块

### 2.1 页面结构
| 模块名称 | 内容描述 |
|---------|---------|
| 顶部Hero区 | 文化传承主题标语 + 校训/励志语 |
| 非遗科普区 | 剪纸艺术介绍（历史、流派、特点） |
| 校园文化区 | 哈尔滨广厦学院介绍 |
| 底部分享区 | 文化金句分享按钮 |
| 弹窗组件 | 文化名言展示弹窗 |

### 2.2 内容要求
**文化传承主题**：
- 简短文字介绍文化传承的意义
- 一句校训或励志语（可用"博学笃行，德才兼备"）

**非遗科普-剪纸艺术**：
- 历史：起源于南北朝，至今1500多年
- 流派：南方纤巧秀丽、北方粗犷豪放
- 特点：线条流畅、构图对称、寓意吉祥
- 技法：阴刻阳刻结合、阴阳对比

**校园文化-哈尔滨广厦学院**：
- 位置：冰城哈尔滨
- 建校：2000年
- 特色：冰雪文化融合、中西文化交汇
- 理念：弘扬传统文化，培养国际视野

## 3. 交互流程

### 3.1 用户流程
```
进入页面 → 浏览各板块内容 → 点击分享按钮 → 弹出名言弹窗 → 点击关闭/确定
```

### 3.2 弹窗交互
- 点击按钮 → 居中弹出动画 → 显示文化名言
- 点击遮罩层或关闭按钮 → 弹窗消失

## 4. 视觉设计

### 4.1 设计风格
- **风格**：中国风、传统美学
- **主色调**：中国红 `#C41E3A` + 米色 `#F5F5DC` + 淡黄色 `#FFFACD`
- **字体**：使用思源宋体/楷体等中文衬线字体
- **布局**：垂直滚动、卡片式布局、适当留白
- **装饰**：传统云纹、水墨山水等中式元素

### 4.2 间距与排版
- 页面内边距：16px-20px
- 卡片间距：24px
- 标题与内容间距：16px
- 正文字体大小：14px-16px
- 标题字体大小：20px-24px

### 4.3 响应式设计
- 移动端优先（适配375px-428px宽度）
- 最大内容宽度：100%
- 图片自适应宽度

## 5. 技术实现

### 5.1 技术栈
- 纯HTML5 + CSS3 + Vanilla JavaScript
- 无需构建工具，单文件实现
- CSS变量管理主题色

### 5.2 动画效果
- 页面加载：淡入动画
- 弹窗：缩放+淡入动画
- 按钮：hover态微缩放
