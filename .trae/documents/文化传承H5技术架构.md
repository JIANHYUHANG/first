# 文化传承 H5页面 技术架构文档

## 1. 技术架构

```
┌─────────────────────────────────┐
│         HTML5 页面结构          │
├─────────────────────────────────┤
│  CSS3 样式与动画                 │
│  - 主题变量                     │
│  - 响应式布局                   │
│  - 动画效果                     │
├─────────────────────────────────┤
│  Vanilla JavaScript             │
│  - 弹窗交互逻辑                 │
│  - DOM操作                      │
└─────────────────────────────────┘
```

## 2. 技术选型

- **页面类型**：单页H5宣传页
- **技术栈**：纯HTML5 + CSS3 + JavaScript（无框架依赖）
- **构建方式**：无需构建工具，直接浏览器运行
- **兼容性**：现代浏览器（Chrome、Safari、Firefox、Edge）

## 3. 页面结构

```html
<!DOCTYPE html>
<html>
├── <head>
│   ├── meta viewport（移动端适配）
│   ├── 字体引入（Google Fonts 思源宋体）
│   └── 内联CSS样式
└── <body>
    ├── Hero主视觉区
    ├── 非遗科普区（剪纸艺术）
    ├── 校园文化区（广厦学院）
    ├── 底部分享按钮
    ├── 弹窗组件
    └── 内联JavaScript
```

## 4. CSS架构

### 4.1 主题变量
```css
:root {
  --primary-red: #C41E3A;    /* 中国红 */
  --bg-cream: #F5F5DC;       /* 米色 */
  --bg-light-yellow: #FFFACD; /* 淡黄色 */
  --text-dark: #333333;
  --text-light: #666666;
}
```

### 4.2 布局系统
- Flexbox弹性布局
- 移动端优先（max-width: 428px）
- 卡片圆角：12px
- 内边距：16px-20px

## 5. 组件定义

### 5.1 Hero区域
- 全宽背景渐变
- 标题+副标题垂直居中
- 装饰性云纹图案

### 5.2 内容卡片
- 白色/米色背景
- 阴影效果
- 内边距20px
- 圆角12px

### 5.3 底部按钮
- 固定定位在底部
- 全宽圆角按钮
- 中国红背景色
- hover微缩放效果

### 5.4 弹窗组件
- 遮罩层：半透明黑色背景
- 弹窗内容：居中卡片
- 动画：scale(0.8)→scale(1) + opacity

const quotes = [

## 7. 性能优化

- 图片使用CSS渐变替代（减少请求）
- 字体使用系统字体回退
- 动画使用transform/opacity（GPU加速）
- 无外部依赖（离线可用）
